## เป้าหมาย

1. แยกต้นทุนเป็นสามก้อน คือครั้งเดียว ต่อชิ้น และต่อเนื่อง
2. คำนวณต้นทุนต่อชิ้นตลอดอายุการใช้งานจากตัวอย่างสมมติ
3. ระบุบทบาทในทีมที่ต้องมี

> **ข้อตกลงของบทนี้** เราไม่ใส่ราคาตลาดหรือสถิติตลาดใด ๆ เพราะราคาเปลี่ยนเร็วและต่างกันมากตามปริมาณและผู้ขาย
> ตัวเลขทุกตัวในตัวอย่างข้างล่างเป็น **ตัวเลขสมมติ** ตั้งขึ้นให้คำนวณง่าย ห้ามนำไปใช้เป็นราคาจริง
> ราคาจริงต้องขอใบเสนอราคาจากผู้ขายและผู้ผลิตรับจ้างเอง

## ก่อนเริ่ม

- จากบทที่แล้ว ต้นทุนของ edge กับ cloud ต่างกันอย่างไร
- ถ้ามีคนถามว่า "ทำอุปกรณ์นี้ราคาเท่าไร" คุณคิดว่าต้องถามอะไรกลับก่อนจะตอบได้

## ดูของจริงก่อน

เจ้าของกิจการหลายคนถามราคาชิ้นส่วนบนบอร์ด แล้วคูณด้วยจำนวนที่จะผลิต ได้ตัวเลขที่ดูน่าพอใจ
แต่ตัวเลขนั้นมักเป็นแค่ส่วนเดียวของต้นทุนจริง ค่าพัฒนา ค่าทดสอบรับรอง ค่าคลาวด์ ค่าซิมการ์ด และค่าดูแลหลังขาย ไม่อยู่ในตัวเลขนั้นเลย
บทนี้ช่วยให้คุณเห็นครบทั้งสามก้อนก่อนตั้งงบ

## แนวคิด

### 1. ต้นทุนสามก้อน

| ก้อน | ภาษาอังกฤษ | ตัวอย่างรายการ |
|---|---|---|
| **ครั้งเดียว** | NRE (non-recurring engineering) | ออกแบบวงจรและแผ่น PCB เขียนเฟิร์มแวร์ ทำแอปหรือแดชบอร์ด เก็บข้อมูลและฝึกโมเดล แม่พิมพ์ตัวเครื่อง ค่าทดสอบและรับรองมาตรฐาน |
| **ต่อชิ้น** | BOM (bill of materials) + assembly | ชิปหรือโมดูล เซนเซอร์ แผ่น PCB ตัวเครื่อง แหล่งจ่ายไฟหรือแบตเตอรี่ ค่าประกอบ ค่าทดสอบในสายการผลิต บรรจุภัณฑ์ |
| **ต่อเนื่อง** | recurring | ค่าคลาวด์ ค่าเชื่อมต่อ (เช่น ซิมการ์ด) ค่าอัปเดตความปลอดภัย ค่าซัพพอร์ตลูกค้า ค่ารับประกันและเปลี่ยนเครื่องเสีย |

AI เพิ่มต้นทุนในก้อนครั้งเดียวมากที่สุด (เก็บข้อมูล ติดป้ายกำกับ ฝึก ทดสอบ) และเพิ่มก้อนต่อเนื่องด้วย (ดูแลโมเดลเมื่อหน้างานเปลี่ยน)

### 2. ตัวอย่างสมมติ: เซนเซอร์เฝ้าตู้แช่

> ตัวเลขทั้งหมดในตัวอย่างนี้เป็นตัวเลขสมมติ ไม่ใช่ราคาตลาด

สมมติว่า

- ต้นทุนครั้งเดียว (NRE) รวม **600,000 บาท**
- ต้นทุนต่อชิ้น (BOM + ประกอบ + ทดสอบ) **900 บาท**
- ต้นทุนต่อเนื่อง **120 บาท ต่อเครื่อง ต่อปี**
- ใช้งานเครื่องละ **3 ปี**

**ถ้าผลิต 1,000 เครื่อง** ต้นทุนต่อเครื่องตลอดอายุ = 600,000 / 1,000 + 900 + (120 x 3) = 600 + 900 + 360 = **1,860 บาท**

**ถ้าผลิต 5,000 เครื่อง** = 600,000 / 5,000 + 900 + 360 = 120 + 900 + 360 = **1,380 บาท**

ข้อสังเกตสองข้อ ข้อแรก เมื่อผลิตมากขึ้น ต้นทุนครั้งเดียวถูกเฉลี่ยจนเหลือน้อย ต้นทุนต่อชิ้นกับต้นทุนต่อเนื่องจึงกลายเป็นก้อนใหญ่
ข้อสอง ต้นทุนต่อเนื่องสามปีในตัวอย่างนี้เกือบครึ่งหนึ่งของต้นทุนต่อชิ้น ถ้าตั้งราคาขายโดยลืมก้อนนี้ ยิ่งขายมากยิ่งขาดทุน

### 3. เวลา: สี่ช่วงที่ไม่ควรข้าม

1. **พิสูจน์แนวคิด (proof of concept)** ใช้บอร์ดพัฒนา ตอบคำถามเดียวว่า "วัดได้และตัดสินใจได้จริงไหม"
2. **ต้นแบบ (prototype)** ใกล้ของจริงขึ้น เริ่มคิดเรื่องตัวเครื่อง พลังงาน และความปลอดภัย
3. **นำร่อง (pilot)** ติดตั้งหน้างานจริงจำนวนน้อย เก็บข้อมูล และเรียนรู้ว่าอะไรพัง
4. **ผลิต (production)** ทดสอบรับรองมาตรฐาน เตรียมสายการผลิตและการดูแลหลังขาย

ช่วงที่คนประเมินเวลาต่ำเกินจริงบ่อยที่สุดคือการเก็บข้อมูลหน้างานสำหรับ AI และการทดสอบรับรองมาตรฐาน
ถามระยะเวลาของสองช่วงนี้จากผู้ที่เคยทำจริงเสมอ

### 4. ทีมที่ต้องมี (คนเดียวอาจทำหลายบทบาท)

- **เจ้าของผลิตภัณฑ์** ตัดสินใจเรื่องขอบเขตและลำดับความสำคัญ (มักเป็นคุณ)
- **ฮาร์ดแวร์** ออกแบบวงจร แผ่น PCB และเลือกชิ้นส่วน
- **เฟิร์มแวร์** เขียนโปรแกรมบนอุปกรณ์
- **คลาวด์และแอป** รับข้อมูล เก็บ แสดงผล และแจ้งเตือน
- **ข้อมูลและ AI** เก็บข้อมูล ฝึก และทดสอบโมเดล (เฉพาะโจทย์ที่ต้องใช้ AI)
- **ทดสอบและมาตรฐาน** ทดสอบคุณภาพ และประสานการรับรองมาตรฐาน
- **ผู้ผลิตรับจ้าง (EMS)** ประกอบและทดสอบในสายการผลิต เมื่อถึงช่วงผลิตจริง

## ฝึกเติม

ใช้ตัวเลขสมมติชุดเดิม แต่เปลี่ยนอายุการใช้งานเป็น **5 ปี** และผลิต **2,000 เครื่อง**
คำนวณต้นทุนต่อเครื่องตลอดอายุ แล้วตอบว่าก้อนไหนใหญ่ที่สุด (ใบ้: 600,000 / 2,000 + 900 + 120 x 5)

จากนั้นเขียนรายการคำถามที่คุณจะถามผู้ขายหรือผู้รับจ้างเพื่อเปลี่ยนตัวเลขสมมติให้เป็นตัวเลขจริง อย่างน้อยสามข้อ เช่น
"ราคาต่อชิ้นที่ 1,000 และ 5,000 ชิ้นต่างกันเท่าไร" "ชิ้นส่วนไหนมีผู้ขายรายเดียว" "ค่าทดสอบรับรองรวมอยู่ในราคาหรือไม่"
