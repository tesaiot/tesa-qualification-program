# โมดูล 1 · เข้าใจทางเลือก

**เป้าหมายของโมดูล** รู้ว่า Edge AI และ IoT ช่วยโจทย์แบบไหนได้จริง เลือกได้ว่าจะคิดบนอุปกรณ์ บนคลาวด์ หรือผสม และมองเห็นต้นทุนครบทั้งสามก้อน

เวลารวมราว 90 นาที ไม่ต้องเขียนโค้ด ไม่ต้องมีบอร์ด

| บทเรียน | เรื่อง | เวลา |
|---|---|---|
| [biz.m01.l01](l01-what-it-can-do/README.md) | Edge AI และ IoT ทำอะไรได้ และทำอะไรไม่ได้ | 30 นาที |
| [biz.m01.l02](l02-edge-cloud-hybrid/README.md) | Edge, Cloud หรือ Hybrid | 30 นาที |
| [biz.m01.l03](l03-cost-bom-team/README.md) | ต้นทุน BOM เวลา และทีม | 30 นาที |

## Checkpoint ท้ายโมดูล

- [ ] โจทย์ของคุณเขียนครบสามส่วน (วัดอะไร ตัดสินใจอะไร ใครทำอะไรต่อ) และบอกได้ว่าหยุดที่ขั้นไหนของบันไดก่อน AI
- [ ] เลือก edge, cloud หรือ hybrid ให้โจทย์ของคุณ พร้อมเหตุผลอย่างน้อยสองมิติ
- [ ] มีรายการต้นทุนสามก้อน และรายการคำถามที่ต้องถามผู้ขายหรือผู้รับจ้าง

สามข้อนี้คือวัตถุดิบของ decision canvas ในโมดูลถัดไป เก็บไว้ให้ดี
