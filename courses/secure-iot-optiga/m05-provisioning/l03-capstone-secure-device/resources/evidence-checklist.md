## 5. ตรวจการรั่วก่อนส่ง

- [ ] ไม่มีรหัสผ่าน MQTT รหัส WiFi หรือ API key ในรายงานและไฟล์แนบ
- [ ] ไม่มีไฟล์จาก bundle ของแพลตฟอร์ม (`ca-chain.pem` เป็นข้อมูลสาธารณะก็จริง แต่ไฟล์ข้อมูลรับรองไม่ใช่)
- [ ] ไม่มีกุญแจลับ รวมถึงกุญแจทดลองจากแล็บ 1.2 และ 5.1
- [ ] ถ้ารายงานจะเผยแพร่ `device_id` และ UID ของชิปถูกปิดบางส่วนแล้ว
