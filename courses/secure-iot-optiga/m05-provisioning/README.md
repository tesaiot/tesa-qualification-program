# โมดูล 5 · การลงทะเบียนอุปกรณ์อย่างปลอดภัย

**เป้าหมายของโมดูล** ลงทะเบียนอุปกรณ์ด้วย CSR ให้กุญแจลับไม่เคยออกจากชิป และรวมทุกอย่างเป็นอุปกรณ์ที่ปลอดภัยหนึ่งชิ้น

สถานะ **alpha** (เนื้อหาครบ รอการทดลองสอนและคำติชม) · เวลาโดยประมาณ 215 นาที

**ข้อตกลงของโมดูล** การลงทะเบียนจริงสร้างคู่กุญแจใหม่ในชิปแทนของเดิม และ Protected Update ทำให้ตัวนับ version ขึ้นถาวร ทั้งสองอย่างต้องได้รับอนุญาตจากผู้สอนก่อน ไม่มีขั้นใดเขียน metadata tag C0 (LcsO)

|---|---|---|
| [sec-iot.m05.l01](l01-csr-enrolment/README.md) | ลงทะเบียนด้วย CSR | 70 นาที |
| [sec-iot.m05.l02](l02-provisioning-screens/README.md) | หน้าจอลงทะเบียนบนอุปกรณ์ | 70 นาที |
| [sec-iot.m05.l03](l03-capstone-secure-device/README.md) | งานปลายทาง: อุปกรณ์ที่ปลอดภัยหนึ่งชิ้น | 75 นาที |

## Checkpoint ท้ายโมดูล

- [ ] อธิบายเส้นทางของ CSR ตั้งแต่สร้างบนชิปจนได้ใบรับรองกลับมา
- [ ] งานปลายทาง: อุปกรณ์หนึ่งชิ้นที่ลงทะเบียน เชื่อม mTLS และส่งข้อมูลขึ้นแพลตฟอร์มได้ พร้อมรายงานหลักฐานและ threat model ที่ปรับแล้ว (รับ Protected Update ด้วยเมื่อผู้สอนอนุญาต)
