Interactive Math Lab — คณิตหลังฉากที่ลากเล่นได้

คณิต/อัลกอริทึมทุกตัวในสไลด์ ทำเป็น GeoGebra สด — ลากจุด เลื่อนสไลเดอร์ แล้วดูสมการขยับตาม เข้าใจ "ทำไม" ไม่ใช่แค่ "จำสูตร". เปิดคู่กับสไลด์บทเรียน 3.1–3.2, 9, 12, 14.

1 · Gradient Descent — ไถลลงหุบ Loss

L(θ) = (θ−2)² + 1 · ก้าว: θ ← θ − η·L′(θ)
▸ เลื่อนสไลเดอร์ θ: เส้นสัมผัส = ความชัน (gradient) — ที่จุดต่ำสุด ความชัน = 0 (โมเดลหยุดเรียน)

2 · Softmax / Sigmoid — คะแนน → ความน่าจะเป็น

σ(z) = 1 / (1 + e^(−z))
▸ เลื่อน z: ดูคะแนนดิบกลายเป็นค่า 0..1 — z มาก → มั่นใจใกล้ 1, z น้อย → ใกล้ 0

3 · สัญญาณผสม → FFT เห็นความถี่

h(x) = sin(a·x) + sin(b·x)
▸ เปลี่ยน a, b: คลื่นผสมเปลี่ยนรูป — FFT คือการถามกลับว่า "มี a กับ b เท่าไร"

4 · Quantization — float ➜ ขั้น int8

q(x) = round(x / s) · s
▸ เลื่อน s (step): เส้นทแยงต่อเนื่องกลายเป็นขั้นบันได — s เล็ก = ละเอียด, s ใหญ่ = หยาบ/เล็กลง

5 · Tilt จาก accelerometer — atan2

roll = atan2(a_y, a_z) · pitch = atan2(−a_x, √(a_y²+a_z²))
▸ ลากเวกเตอร์แรงโน้มถ่วง g (จุด A): มุมเอียงคำนวณจาก atan2 — หัวใจของ dsp.tilt() ในบทเรียน 3.1–3.2
