# โมดูล 5 · UART, I2C และ SPI กับ logic analyzer

**เป้าหมายของโมดูล** สื่อสารผ่านบัสพื้นฐานสามแบบ และยืนยันด้วยสัญญาณจริงบน logic analyzer

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 210 นาที

ทุกบทเรียนมีเนื้อหา ตัวอย่างที่รันบนคอมพิวเตอร์ได้ แบบฝึกพร้อมเฉลย เช็กความเข้าใจ และแล็บ โค้ดของหลักสูตรรันและตรวจบนคอมพิวเตอร์แล้ว ส่วนแล็บบนบอร์ดยังรอการทดลองสอน

| บทเรียน | เรื่อง | เวลา |
|---|---|---|
| [c-found.m05.l01](l01-uart/README.md) | UART | 70 นาที |
| [c-found.m05.l02](l02-i2c/README.md) | I2C | 70 นาที |
| [c-found.m05.l03](l03-spi/README.md) | SPI | 70 นาที |

## Checkpoint ท้ายโมดูล

- [ ] จับเฟรม UART จริงจากขาของบอร์ด ถอดรหัสด้วยตาก่อน แล้วยืนยันด้วย decoder
- [ ] จับสัญญาณ I2C ขณะสแกนบัส แล้วถอดรหัส address และ ACK ด้วย logic analyzer
- [ ] จับธุรกรรม SPI แล้วพิสูจน์ด้วยภาพว่าการตั้งโหมดผิดให้ไบต์ผิด
- [ ] อธิบายความต่างของ UART, I2C และ SPI ในสามมิติ คือจำนวนสาย การระบุอุปกรณ์ และความเร็ว
