# โมดูล 4 · Timer, Interrupt, Watchdog, DMA และสัญญาณนาฬิกา

**เป้าหมายของโมดูล** ใช้อุปกรณ์ต่อพ่วงหลักของไมโครคอนโทรลเลอร์ตามกติกาของบริบท ISR และ RTOS

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 280 นาที

ทุกบทเรียนมีเนื้อหา ตัวอย่างที่รันบนคอมพิวเตอร์ได้ แบบฝึกพร้อมเฉลย เช็กความเข้าใจ และแล็บ โค้ดของหลักสูตรรันและตรวจบนคอมพิวเตอร์แล้ว ส่วนแล็บบนบอร์ดยังรอการทดลองสอน

## Checkpoint ท้ายโมดูล

- [ ] อ่านปุ่มด้วย interrupt และกันเด้งโดยไม่บล็อก โดย ISR ทำงานน้อยที่สุดแล้วส่งงานต่อให้ task
- [ ] คำนวณความถี่ของตัวตั้งเวลาจากค่าตั้งใน BSP ได้ถูก (ตัวหาร N หารด้วย N+1) และอธิบายผลของสัญญาณนาฬิกาต่อความแม่นยำ
- [ ] อธิบายตำแหน่งที่ถูกต้องของการป้อน watchdog ในโปรแกรมตัวอย่าง และอ่านสาเหตุการรีเซ็ตของบอร์ดจริงได้
- [ ] ชี้ได้ว่าจุดไหนในไดรเวอร์กล้องของ SDK ที่ต้อง clean cache ก่อนให้ DMA อ่าน และบัฟเฟอร์ไหนวางในหน่วยความจำที่ไม่ผ่าน cache เพราะอะไร
