# โมดูล 6 · Unit test และ CI

**เป้าหมายของโมดูล** ทดสอบตรรกะของเฟิร์มแวร์บนเครื่องโฮสต์ และให้ CI ตรวจทุกการเปลี่ยนแปลง

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 140 นาที

ทุกบทเรียนมีเนื้อหา ตัวอย่างที่รันบนคอมพิวเตอร์ได้ แบบฝึกพร้อมเฉลย เช็กความเข้าใจ และแล็บ โค้ดของหลักสูตรรันและตรวจบนคอมพิวเตอร์แล้ว ส่วนแล็บบนบอร์ดยังรอการทดลองสอน

## Checkpoint ท้ายโมดูล

- [ ] มี unit test อย่างน้อยห้ากรณีที่รันบนเครื่องโฮสต์ และพิสูจน์ได้ว่าอย่างน้อยหนึ่งกรณีล้มเหลวได้จริง
- [ ] ใส่บั๊กอย่างน้อยสามแบบลงในตรรกะของคุณ แล้ว test จับได้ทุกแบบ (ไม่มีแบบที่ survived)
- [ ] มี workflow ของ CI ที่รัน test ตรวจรูปแบบ วิเคราะห์แบบสถิต และคอมไพล์สำหรับ Cortex-M ทุก pull request
- [ ] มี pull request ที่ CI แดงจากบั๊กที่ตั้งใจใส่ เป็นหลักฐานว่าการตรวจล้มเป็น
