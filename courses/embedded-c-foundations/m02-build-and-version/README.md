## Checkpoint ท้ายโมดูล

- [ ] build แม่แบบเฟิร์มแวร์จากไฟล์ zip ของ release สำเร็จ แฟลชลงบอร์ด เห็นบรรทัด `[HB]` บน console และบันทึกเวอร์ชันของเครื่องมือที่ใช้
- [ ] เปิดตัวอย่างหนึ่งตัวด้วยตัวแปร Make แล้วเห็นผลบนบอร์ด และวัดได้ว่าขนาดเฟิร์มแวร์เปลี่ยนเท่าไร
- [ ] มี repository ที่ไม่มีไฟล์ build และไม่มีข้อมูลลับ พร้อม hook `pre-commit` ที่ผ่านชุดทดสอบของบทเรียน 2.3
