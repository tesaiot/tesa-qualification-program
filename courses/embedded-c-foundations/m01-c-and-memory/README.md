# โมดูล 1 · ภาษา C สำหรับไมโครคอนโทรลเลอร์และหน่วยความจำ

**เป้าหมายของโมดูล** เขียน C ที่ทำงานกับบิต รีจิสเตอร์ และหน่วยความจำได้อย่างปลอดภัยบนไมโครคอนโทรลเลอร์

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 210 นาที

ทุกบทเรียนมีเนื้อหา ตัวอย่างที่รันบนคอมพิวเตอร์ได้ แบบฝึกพร้อมเฉลย เช็กความเข้าใจ และแล็บ โค้ดของหลักสูตรรันและตรวจบนคอมพิวเตอร์แล้ว ส่วนแล็บบนบอร์ดยังรอการทดลองสอน
