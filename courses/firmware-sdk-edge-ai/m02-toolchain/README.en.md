
# Module 2 — ModusToolbox™ and VS Code for Firmware Development

*ModusToolbox™ and VS Code for Firmware Development* · [TESA Firmware SDK for Edge AI](../README.md) course

## Objectives

Get your development machine genuinely ready: install ModusToolbox™ + VS Code, create a project from the BSP that matches your kit, then build, flash, and debug on the board.

## Lessons

| # | Lesson | Content |
|---|---|---|
| 1 | [ModusToolbox™ and VS Code: create, build, flash, debug](l01-modustoolbox-and-vscode/README.md) | Telling apart the roles of ModusToolbox™, VS Code, KitProg3 and the SDK, setting up a complete environment, choosing the BSP that matches your kit, and knowing how to troubleshoot common problems |
| 2 | [Lab: create, build, flash and debug a firmware project](l02-lab/README.md) | Checking your machine, creating a project from the BSP, building in VS Code, flashing the board, and debugging at least once |

Approximate time per the original: about 2.5–3 hours (lessons) + a 90–120 minute lab.

Accompanying sheets and templates (in the `resources/` folder of lesson 1):

- [toolchain-cheatsheet.md](l01-modustoolbox-and-vscode/resources/toolchain-cheatsheet.md)

## Checkpoint

Before moving to the next module, check that you can do the following:

- [ ] Successfully build the example project, or successfully flash a HEX from the lab pack
- [ ] Program the board and see confirmable behaviour (an LED, or a serial message)
- [ ] Open a debug session and halt at main or a breakpoint at least once
