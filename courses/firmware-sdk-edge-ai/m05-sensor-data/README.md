# โมดูล 5 — ข้อมูลเซ็นเซอร์และการเตรียมข้อมูลสำหรับ Edge AI

*Sensor Data and Edge AI Preparation* · หลักสูตร [TESA Firmware SDK สำหรับ Edge AI](../README.md)

## เป้าหมาย

ทำให้ข้อมูลเซ็นเซอร์พร้อมสำหรับ Edge AI: อ่านด้วยคาบเวลาคงที่ กรอง normalize จัดหน้าต่างข้อมูล และส่งต่อไปโฮสต์หรือ Digital Twin

## บทเรียน

| # | บทเรียน | เนื้อหา |
|---|---|---|
| 1 | [สตรีมเซ็นเซอร์ที่พร้อมสำหรับ Edge AI](l01-sensor-data-for-edge-ai/README.md) | จากขาเซ็นเซอร์สู่สตรีมที่พร้อมเข้าโมเดล: คาบเวลาคงที่ ตัวกรอง normalize หน้าต่างข้อมูล และการส่งต่อไปโฮสต์ |
| 2 | [แล็บ: สตรีมเซ็นเซอร์และหน้าต่างข้อมูลพร้อม AI](l02-lab/README.md) | อ่านเซ็นเซอร์สองชนิดด้วย task คาบคงที่ กรองหรือ normalize สร้างหน้าต่างข้อมูล แล้วเลือกต่อยอด (fusion, host telemetry หรือ event) |

เวลาโดยประมาณตามต้นฉบับ: ประมาณ 3.5–4 ชั่วโมง (บทเรียน) + แล็บ 2.5–3.5 ชั่วโมง

ชีตและแม่แบบประกอบ (อยู่ในโฟลเดอร์ `resources/` ของบทเรียนที่ 1):

- [sensor-ai-prep.md](l01-sensor-data-for-edge-ai/resources/sensor-ai-prep.md)

> โค้ด C ในโมดูลนี้ใช้ API ของเฟิร์มแวร์ TESAIoT Bitstream ซึ่งยังไม่เปิดซอร์ส อ่านหมายเหตุต้น[บทเรียน](l01-sensor-data-for-edge-ai/README.md) ก่อนลงมือ

## จุดตรวจ

ก่อนไปโมดูลถัดไป ตรวจว่าคุณทำสิ่งเหล่านี้ได้แล้ว:

- [ ] อ่านเซ็นเซอร์ได้อย่างน้อยสองชนิดใน task คาบเวลาคงที่
- [ ] มีตัวกรองหรือ normalize อย่างน้อยหนึ่งแบบในโค้ดแล็บ
- [ ] หน้าต่างข้อมูลให้เวกเตอร์สรุปอย่างน้อยหนึ่งครั้งต่อวินาที
- [ ] กรอกตารางใน sensor-ai-prep.md และรายงานสั้นครบ
