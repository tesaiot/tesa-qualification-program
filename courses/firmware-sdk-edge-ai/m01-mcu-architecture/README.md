# โมดูล 1 — สถาปัตยกรรม MCU และโครงสร้าง Firmware SDK

*MCU Architecture and Firmware SDK Structure* · หลักสูตร [TESA Firmware SDK สำหรับ Edge AI](../README.md)

## เป้าหมาย

วางแผนที่ความคิดของทั้งหลักสูตร: รู้ว่างานแต่ละแบบควรอยู่โดเมนไหนของ PSOC™ Edge E84 และโค้ดแต่ละส่วนควรอยู่ชั้นซอฟต์แวร์ไหน ก่อนเริ่มติดตั้งเครื่องมือในโมดูลถัดไป โมดูลนี้ยังไม่ต้อง flash บอร์ด
