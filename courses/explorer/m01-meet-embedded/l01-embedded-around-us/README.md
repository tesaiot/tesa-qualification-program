## เป้าหมาย

เมื่อจบบทเรียนนี้ คุณจะ

1. ระบุส่วนรับรู้ ส่วนตัดสินใจ และส่วนสั่งงาน ของอุปกรณ์ในบ้านได้อย่างน้อย 3 ชิ้น
2. อธิบายได้ว่าไมโครคอนโทรลเลอร์ต่างจากคอมพิวเตอร์ทั่วไปอย่างไร อย่างน้อย 2 ประเด็น
3. จำแนกได้ว่าอุปกรณ์ใดมีระบบสมองกลฝังตัว

บทนี้ไม่ต้องมีบอร์ด ไม่ต้องติดตั้งอะไร ใช้แค่ตากับกระดาษหนึ่งแผ่น

## ก่อนเริ่ม

ลองตอบในใจสองข้อนี้ก่อน ไม่ต้องกลัวผิด

- ในบ้านคุณมีของกี่ชิ้นที่ "รู้" ว่าตอนนี้กี่โมง
- หม้อหุงข้าวรู้ได้อย่างไรว่าข้าวสุกแล้ว

คำตอบของสองข้อนี้คือเรื่องทั้งหมดของบทเรียนนี้

## ดูของจริงก่อน

เดินรอบบ้านหรือห้องทำงานสักสองนาที แล้วจดของที่มีปุ่ม มีไฟ มีจอ หรือส่งเสียงเตือนได้ เช่น
เครื่องซักผ้า ไมโครเวฟ รีโมตแอร์ นาฬิกาข้อมือ ลิฟต์ ไฟจราจร ตู้เย็นรุ่นใหม่ เครื่องวัดความดัน

ของเกือบทุกชิ้นในรายการนี้มีคอมพิวเตอร์ตัวเล็ก ๆ ซ่อนอยู่ข้างใน คอมพิวเตอร์ตัวนี้ไม่มีคีย์บอร์ด ไม่มีเมาส์
และคนส่วนใหญ่ไม่เคยรู้ว่ามันอยู่ตรงนั้น นี่แหละคือ **ระบบสมองกลฝังตัว (embedded system)**

## แนวคิด

### 1. รับรู้ ตัดสินใจ สั่งงาน

ระบบสมองกลฝังตัวเกือบทุกชิ้นทำงานวนสามจังหวะเดิมซ้ำไปเรื่อย ๆ

| จังหวะ | ภาษาอังกฤษ | ตัวอย่างในหม้อหุงข้าวดิจิทัล (รุ่นที่มีจอและปุ่มเลือกโหมด) |
|---|---|---|
| รับรู้ | sense (ผ่าน **เซนเซอร์ / sensor**) | เซนเซอร์อุณหภูมิที่ก้นหม้อ |
| ตัดสินใจ | decide (ด้วย **ไมโครคอนโทรลเลอร์ / microcontroller**) | "ร้อนเกินจุดหนึ่งแล้ว แปลว่าน้ำหมด ข้าวสุก" |
| สั่งงาน | act (ผ่าน **แอคชูเอเตอร์ / actuator**) | ตัดไฟขดลวดความร้อน เปลี่ยนเป็นโหมดอุ่น เปิดไฟสถานะ |

หม้อหุงข้าวรุ่นดั้งเดิมที่มีคันโยกอันเดียวก็รู้ว่าข้าวสุกได้เหมือนกัน แต่ใช้กลไกตัดไฟตามความร้อน (thermostat) ไม่มีคอมพิวเตอร์อยู่ข้างใน
ของสองชิ้นที่ทำงานเดียวกันจึงอาจเป็นระบบสมองกลฝังตัวชิ้นหนึ่ง และไม่ใช่อีกชิ้นหนึ่ง

ลองใช้สามช่องนี้กับเครื่องซักผ้าดู เซนเซอร์วัดระดับน้ำคือส่วนรับรู้ โปรแกรมซักคือส่วนตัดสินใจ
มอเตอร์กับวาล์วน้ำคือส่วนสั่งงาน พอเห็นแบบนี้ครั้งหนึ่งแล้ว คุณจะเห็นมันในทุกอย่าง

### 2. ไมโครคอนโทรลเลอร์ไม่ใช่คอมพิวเตอร์ย่อส่วน

คอมพิวเตอร์บนโต๊ะถูกออกแบบให้ทำได้ทุกอย่าง เปิดเว็บ พิมพ์งาน เล่นเกม ส่วน **ไมโครคอนโทรลเลอร์** ถูกออกแบบให้ทำงานเดียว
ให้ดี ให้ตรงเวลา และให้กินไฟน้อย ความต่างที่เห็นชัดมีอย่างน้อยสามข้อ

- **งานเฉพาะ** โปรแกรมเดียวรันตั้งแต่เปิดเครื่องจนปิดเครื่อง ไม่มีใครมาติดตั้งแอปเพิ่ม
- **ตรงเวลา** ถุงลมนิรภัยต้องพองในเวลาที่กำหนด ช้าไปนิดเดียวก็ไม่มีประโยชน์ งานแบบนี้เรียกว่างาน **เวลาจริง (real-time)**
- **ประหยัดพลังงานและตัวเล็ก** หลายชิ้นใช้ถ่านก้อนเดียวได้เป็นปี และทั้งระบบอยู่บนชิปเดียว (หน่วยประมวลผล หน่วยความจำ และขาต่ออุปกรณ์อยู่ในชิปเดียวกัน)

### 3. แล้วอะไรไม่ใช่

ของที่ไม่มีการตัดสินใจเลย เช่น สวิตช์ไฟธรรมดาที่แค่ต่อหรือตัดวงจร หรือไฟฉายที่กดแล้วติด ไม่ถือเป็นระบบสมองกลฝังตัว
แม้จะมีไฟฟ้าวิ่งอยู่ก็ตาม ถ้าไม่มีส่วนที่ "คิด" ก็ยังไม่ใช่

## ฝึกเติม

หยิบกระดาษมาตีตารางสามช่องแบบข้างล่าง แล้วเติมให้ครบอย่างน้อยสามแถวจากของที่คุณจดไว้ตอน "ดูของจริงก่อน"

| อุปกรณ์ | รับรู้อะไร (เซนเซอร์) | ตัดสินใจอะไร | สั่งอะไร (แอคชูเอเตอร์) |
|---|---|---|---|
| ตัวอย่าง: แอร์ | อุณหภูมิห้อง | "ห้องยังร้อนกว่าที่ตั้งไว้" | คอมเพรสเซอร์ พัดลม |
| | | | |
| | | | |
| | | | |

ถ้าช่องไหนเติมไม่ได้ ลองถามว่า "มันรู้ได้อย่างไร" และ "มันทำอะไรต่อ" สองคำถามนี้มักพาไปเจอคำตอบ

## เช็กความเข้าใจ

ตอบคำถามใน [quiz.yaml](quiz.yaml) ถูกตั้งแต่ 80% ขึ้นไปถือว่าผ่านบทเรียนนี้

## ไปต่อ

ลองคิดต่อว่า ถ้าเซนเซอร์อุณหภูมิในหม้อหุงข้าวเสีย แล้วรายงานค่าเย็นตลอดเวลา อะไรจะเกิดขึ้น
คำถามแบบนี้คือสิ่งที่วิศวกรระบบฝังตัวต้องคิดทุกวัน ระบบที่ดีต้องรู้ตัวเมื่อเซนเซอร์ของตัวเองโกหก

บทถัดไป [รู้จักบอร์ดและอีมูเลเตอร์](../l02-board-and-emulator/README.md) เราจะได้เห็นไมโครคอนโทรลเลอร์ของจริงหนึ่งตัว
และลองสั่งมันผ่านเบราว์เซอร์โดยไม่ต้องมีบอร์ด

## สะท้อนคิด

อุปกรณ์ชิ้นไหนในบ้านที่คุณแปลกใจที่สุดว่ามีคอมพิวเตอร์อยู่ข้างใน และถ้าให้ออกแบบใหม่ คุณอยากให้มันรับรู้อะไรเพิ่ม
