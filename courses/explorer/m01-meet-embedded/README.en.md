
# Module 1 · Meet embedded systems and write a first program

**Module goal** See the embedded systems in everyday life, get to know the board and the emulator, then write a first
MicroPython program that puts text on the screen and turns on a light.

About 80 minutes in total, and all of it can be done without a board.

| Lesson | Topic | Time |
|---|---|---|
| [explore.m01.l01](l01-embedded-around-us/README.md) | Embedded systems all around you | 25 min |
| [explore.m01.l02](l02-board-and-emulator/README.md) | Meet the board and the emulator | 25 min |
| [explore.m01.l03](l03-first-program/README.md) | First program: draw on the screen and light an LED | 28 min |

## End-of-module checkpoint

You pass this module when you can do all three.

- [ ] Fill in the "sense, decide, act" table for at least three devices
- [ ] Run the example file in the BENTO Emulator (or on a board) until you see the board name on the screen
- [ ] Complete [practice/blink_count.py](l03-first-program/practice/blink_count.py) so the LED blinks the right number of times and the number on the screen matches, then keep a screenshot in your portfolio

If you get stuck anywhere, go back and read the "Concepts" section of that lesson again, then try once more. There is no rush.
