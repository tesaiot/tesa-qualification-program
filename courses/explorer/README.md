# Explorer: เปิดโลกระบบสมองกลฝังตัว

ระดับ **L1 รู้จัก** · สถานะ **alpha** · 6 บทเรียน บทละ 20–30 นาที · รวมราว 3 ชั่วโมง · **ไม่ต้องมีบอร์ด**

หลักสูตรสั้นสำหรับทุกคนที่อยากรู้ว่าคอมพิวเตอร์ตัวเล็ก ๆ ที่ซ่อนอยู่ในหม้อหุงข้าว เครื่องซักผ้า และนาฬิกาข้อมือ ทำงานอย่างไร
เราเริ่มจากมองหามันรอบตัว แล้วลงมือเขียนโปรแกรม MicroPython บรรทัดแรกใน **BENTO Emulator** ซึ่งเปิดได้ในเบราว์เซอร์
ให้ข้อความขึ้นจอ ไฟกะพริบ อ่านค่าเซนเซอร์ และส่งค่าไปโผล่บนหน้าเว็บ ถ้ามีบอร์ด Eva Kit หรือ TESAIoT Dev Kit อยู่แล้ว โค้ดชุดเดียวกันรันบนบอร์ดได้ทันที

## เหมาะกับใคร

- บุคคลทั่วไป ผู้ปกครอง และนักเรียนที่ไม่เคยเขียนโปรแกรมมาก่อน
- ผู้ประกอบการที่อยากเห็นของจริงสักครั้งก่อนตัดสินใจเรื่องผลิตภัณฑ์
- ผู้สอนที่อยากได้บทเรียนเปิดตัวหัวข้อระบบฝังตัวให้ผู้เรียน

สิ่งที่ต้องมี: คอมพิวเตอร์หรือแท็บเล็ตที่เปิดเบราว์เซอร์ Chrome หรือ Edge ได้ และอินเทอร์เน็ต (บทเรียนนี้ไม่ได้ออกแบบสำหรับจอมือถือ)

## เมื่อจบหลักสูตร คุณจะทำได้

1. ยกตัวอย่างระบบสมองกลฝังตัวในชีวิตประจำวัน และแยกส่วนรับรู้ ตัดสินใจ และสั่งงานของมันได้
2. รันโปรแกรม MicroPython ใน BENTO Emulator หรือบนบอร์ด ให้แสดงข้อความบนจอและควบคุมหลอด LED ได้
3. อ่านค่าเซนเซอร์และแสดงค่าที่เปลี่ยนไปบนจอได้ โดยดักกรณีที่ยังอ่านค่าไม่ได้
4. อธิบายการทำงานของ MQTT และส่งค่าหนึ่งค่าไปแสดงบนหน้าเว็บตามตัวอย่างนำทางได้
5. เลือกเส้นทางเรียนต่อที่ตรงกับเป้าหมาย และอ้างอิง TESA ได้ถูกต้องเมื่อแบ่งปันหรือดัดแปลงเนื้อหา

## เรียนอย่างไร

ทุกบทเรียนมีโครงเดียวกัน เริ่มจาก "ดูของจริงก่อน" ให้เห็นผลภายในไม่กี่นาทีแรก แล้วค่อยอ่านแนวคิด
ตัวอย่างโค้ดทุกไฟล์รันได้ครบ ไฟล์ฝึกมีช่องให้เติมที่ค่อย ๆ มากขึ้นทีละบท และทุกบทจบด้วยเช็กความเข้าใจสั้น ๆ ใน `quiz.yaml`
ตอบถูกตั้งแต่ 80% ขึ้นไปถือว่าผ่านบทนั้น

**ลองเองโดยไม่ต้องมีบอร์ด** ทุกบทเรียนทำได้ใน BENTO Emulator ใน [BENTO IDE](https://ide.tesaiot.dev/) ถ้ามีบอร์ด ทุกบทบอกวิธีรันบนบอร์ดไว้ด้วย
หลักคิดของเราคือ ใช้อีมูเลเตอร์เรียนแนวคิด ใช้บอร์ดจริงพิสูจน์และวัดผล
