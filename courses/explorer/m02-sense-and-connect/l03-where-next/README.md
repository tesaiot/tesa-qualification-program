## เป้าหมาย

1. เลือกเส้นทางเรียนต่อที่ตรงกับเป้าหมายของคุณ พร้อมเหตุผล
2. อ้างอิง TESA ให้ถูกเมื่อแบ่งปันหรือดัดแปลงเนื้อหา
3. รวบรวมผลงานจาก Explorer เป็น portfolio

## ก่อนเริ่ม

- จากบทที่แล้ว ทำไม broker สาธารณะที่พอร์ต 1883 จึงไม่เหมาะกับข้อมูลจริง
- ในหกบทที่ผ่านมา บทไหนที่คุณอยากทำต่อมากที่สุด

## ดูของจริงก่อน

เปิดโฟลเดอร์หรืออัลบั้มที่คุณเก็บภาพหน้าจอจากบทก่อน ๆ ไว้ แล้วนับดูว่ามีกี่ชิ้น
ของเหล่านี้คือหลักฐานว่าคุณทำอะไรได้แล้ว ไม่ใช่แค่ "เคยอ่าน" มาแล้ว

## แนวคิด

### 1. ห้าเส้นทาง เลือกตามเป้าหมาย ไม่ใช่ตามความยาก

TESA Open Knowledge จัดหลักสูตรเป็นห้าเส้นทาง รายละเอียดทั้งหมดอยู่ใน [catalog/tracks.yaml](../../../../catalog/tracks.yaml)

| ถ้าคุณอยาก... | เส้นทาง | ก้าวถัดไป |
|---|---|---|
| ลองต่ออีกนิดเพื่อความสนุกหรือเพื่อเข้าใจลูกหลาน | ผู้เริ่มต้น (explorer) | โมดูลแรกของหลักสูตร AIoT in Action |
| ตัดสินใจเรื่องผลิตภัณฑ์หรือการลงทุน โดยไม่ต้องเขียนโค้ด | ผู้ประกอบการ (entrepreneur) | หลักสูตร [Edge AI และ IoT สำหรับการตัดสินใจเชิงผลิตภัณฑ์](../../../edge-ai-iot-for-business/README.md) |
| เรียนเป็นระบบเพื่อทำโปรเจกต์หรือสมัครงาน | นักศึกษา (student) | AIoT in Action แล้วต่อด้วยเฟิร์มแวร์ภาษา C |
| ยกระดับทักษะเพื่องานที่ทำอยู่ | นักพัฒนา (developer) | ทำแบบทดสอบจัดระดับ แล้วข้ามไประดับที่เหมาะ |
| นำไปสอนในสถานศึกษา | ผู้สอน (educator) | หลักสูตร [ชุดสำหรับผู้สอน](../../../educator-kit/README.md) |

ไม่มีเส้นทางไหนดีกว่าเส้นทางอื่น เลือกจากคำถามว่า "อีกสามเดือนข้างหน้า ฉันอยากทำอะไรได้"

### 2. เรียนคนเดียวมักไม่จบ หาเพื่อนเรียน

งานวิจัยเรื่องคอร์สออนไลน์แบบเปิดพบว่าผู้ลงทะเบียนส่วนน้อยมากที่เรียนจนจบ สิ่งที่ช่วยได้จริงคือโครงสร้าง
เช่น เรียนเป็นรุ่นพร้อมคนอื่น มีกำหนดส่ง และมีคนคอยตอบ ถ้ามีรุ่นเรียนหรือค่ายของ TESA เปิด ลองเข้าร่วม
หรือชวนเพื่อนสองสามคนเรียนไปพร้อมกันก็ช่วยได้มาก

### 3. แบ่งปันได้ แต่ต้องอ้างอิง TESA ทุกครั้ง

เนื้อหาใน TESA Open Knowledge เผยแพร่ภายใต้สัญญาอนุญาต **CC BY-NC 4.0** แปลว่าคุณนำไปแบ่งปัน ใช้สอน และดัดแปลงได้ ถ้าไม่ใช่เพื่อการค้า (ถ้าจะใช้เพื่อการค้า ต้องขออนุญาต TESA ก่อน)
โดยมีเงื่อนไขสำคัญคือ **ต้องอ้างอิงที่มา** ตามรูปแบบที่ TESA กำหนด ข้อความอ้างอิงสำหรับหลักสูตรนี้คือ

> "Explorer: เปิดโลกระบบสมองกลฝังตัว" จาก TESA Open Knowledge โดยสมาคมสมองกลฝังตัวไทย (Thai Embedded Systems Association: TESA)
> https://github.com/tesaiot/tesa-qualification-program สัญญาอนุญาต CC BY-NC 4.0

กติกาสามข้อที่ควรจำ

- **ถ้าแก้ไขเนื้อหา** ให้เติมคำว่า **(ดัดแปลง)** ต่อท้ายข้อความอ้างอิง และถ้าทำได้ให้บอกสั้น ๆ ว่าเปลี่ยนอะไร เพื่อให้ผู้อ่านรู้ว่าไม่ใช่ต้นฉบับ
- **โค้ดตัวอย่าง** ในหลักสูตรนี้ดัดแปลงจากหลักสูตร AIoT in Action ภายใต้สัญญาอนุญาต MIT ต้องคงบรรทัดลิขสิทธิ์ที่หัวไฟล์ไว้เสมอ
- **อย่าอ้างว่า TESA รับรอง** งานหรือคอร์สของคุณ การอ้างอิงที่มาไม่ได้แปลว่า TESA รับรองหรือสนับสนุน

รายละเอียดและตัวอย่างการอ้างอิงในสไลด์ เอกสารแจก และโพสต์ อยู่ในไฟล์ [ATTRIBUTION.md](../../../../ATTRIBUTION.md) ที่รากของคลังความรู้

### 4. portfolio คือหลักฐาน

portfolio ไม่ต้องหรูหรา โฟลเดอร์เดียวที่มีภาพหน้าจอ ไฟล์โค้ดที่คุณแก้ และแผนภาพที่วาดเองพร้อมคำอธิบายสั้น ๆ ก็พอ
ถ้าใช้ GitHub เป็น จะเก็บเป็น repository สาธารณะก็ได้ แต่ **ตรวจก่อนทุกครั้งว่าไม่มีรหัส WiFi หรือรหัสผ่านใด ๆ อยู่ในไฟล์**

TESA วางแผนออกหลักฐานการเรียนจบ (TQP T0 Open Knowledge Completion) สำหรับผู้ที่ผ่านเช็กท้ายบท โดยนับเฉพาะบทเรียนสถานะ `stable`
ซึ่งหลักสูตรนี้ (สถานะ alpha) ยังไม่ถึง ดูกติกาและสถานะล่าสุดได้ที่ [tqp/certification.md](../../../../tqp/certification.md)
T0 ยืนยันการเรียนจบ ไม่ใช่การรับรองสมรรถนะ

## ฝึกเติม

1. เขียนประโยคเดียว "อีกสามเดือนข้างหน้า ฉันอยาก..." แล้วเลือกเส้นทางหนึ่งจากตาราง
2. สมมติว่าคุณจะนำบทเรียน "โปรแกรมแรก: เขียนบนจอและเปิดไฟ" ไปทำเป็นโพสต์สอนเพื่อน โดยแก้ตัวอย่างให้กะพริบเป็นรหัสมอร์ส
   เขียนข้อความอ้างอิงที่จะวางท้ายโพสต์ให้ถูกต้อง (ใบ้: มีการแก้ไข ต้องมีคำว่า ดัดแปลง)

## เช็กความเข้าใจ

ตอบคำถามใน [quiz.yaml](quiz.yaml) ถูกตั้งแต่ 80% ขึ้นไปถือว่าผ่าน และถือว่าจบหลักสูตร Explorer

## แล็บ

รวบรวม portfolio ของ Explorer ให้มีอย่างน้อยสามชิ้น

- [ ] ตาราง "รับรู้ ตัดสินใจ สั่งงาน" จากบทแรก
- [ ] ภาพหน้าจอของโปรแกรมไฟกะพริบหรือไฟเตือนเมื่อเอียง
- [ ] แผนภาพเส้นทางข้อความ MQTT จากบทที่แล้ว
