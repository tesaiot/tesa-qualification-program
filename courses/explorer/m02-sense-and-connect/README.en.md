
# Module 2 · Sense, connect, and move on

**Module goal** Read a sensor value and see it on the screen, send the value out for others to see over MQTT, then pick a path to continue learning and know how to share your content correctly.

About 85 minutes in total, and all of it can be done in the BENTO Emulator (the second lesson needs the internet).

| Lesson | Topic | Time |
|---|---|---|
| [explore.m02.l01](l01-read-a-sensor/README.md) | Read a sensor and watch the value change | 28 min |
| [explore.m02.l02](l02-connected-things/README.md) | Things that can talk to each other: MQTT and a dashboard | 30 min |
| [explore.m02.l03](l03-where-next/README.md) | Where to go next, and how to share your work correctly | 25 min |

## End-of-module checkpoint

- [ ] Complete [practice/tilt_alarm.py](l01-read-a-sensor/practice/tilt_alarm.py) so the light turns on when tilted and off when lying flat
- [ ] Send the value to a web page where it can be read, or explain from the label on the screen which stage it is at and why
- [ ] Write a correct TESA attribution notice for a piece of work you have adapted
- [ ] Have at least three pieces in your portfolio from this course

Using fewer hints as you go is intentional. The practice files in this module have more blanks to fill in than the first module, because you have gotten better.
