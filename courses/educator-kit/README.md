# ชุดสำหรับผู้สอน (Educator Kit)

ระดับ **L3 ทำได้เอง** · สถานะ **alpha** · 7 บทเรียน · เรียนเองราว 6 ชั่วโมง บวกเวิร์กช็อป train-the-trainer สองวันที่ TESA จัด

ชุดนี้สำหรับอาจารย์ในมหาวิทยาลัยและวิทยาลัย ครูผู้สอนสายเทคนิค และวิทยากรที่จะนำหลักสูตรของ TESA Open Knowledge ไปใช้
เราไม่ได้ส่งรายวิชาสำเร็จรูปให้คุณสอนตามทั้งก้อน แต่ส่งชิ้นส่วนที่ต่อกันได้ พร้อมวิธีต่อให้เข้ากับรายวิชา มาตรฐานคุณวุฒิ
และข้อจำกัดของสถาบันคุณ ชุดนี้ใช้ Arm Education Kits และคู่มือผู้สอนของ Microsoft IoT for Beginners เป็นต้นแบบ

## เหมาะกับใคร

- อาจารย์ที่สอนวิชาไมโครคอนโทรลเลอร์ ระบบฝังตัว IoT หรือ Edge AI
- ผู้สอนในค่ายและกิจกรรมเตรียมแข่งขัน
- ผู้ที่ต้องการเป็น TQP Certified Trainer

แนะนำให้ทำหลักสูตร [Explorer](../explorer/README.md) ก่อน เพื่อเห็นรูปแบบบทเรียนจากมุมผู้เรียน

## เมื่อจบหลักสูตร คุณจะทำได้

1. เลือกรูปแบบการนำหลักสูตรไปใช้ที่เหมาะกับบริบทของสถาบัน และจัดบทเรียนลงช่วงสอน 1.5 หรือ 3 ชั่วโมงได้
2. ทำตารางเทียบรายบทเรียนกับ CLO ที่วัดผลได้ ด้าน K/S/E/C หน่วยสมรรถนะ TPQI และคุณลักษณะ WA ได้ครบทุกคอลัมน์
3. ใส่ข้อความอ้างอิง TESA ในเอกสารรายวิชา สไลด์ เอกสารแจก และหน้า LMS ได้ถูกต้อง โดยไม่อ้างการรับรองที่ไม่มี
4. ออกแบบกิจกรรมตาม PRIMM ไฟล์ฝึกที่ตัวช่วยลดลง แบบฝึก Parsons และงานให้คะแนนที่ผูกกับเป้าหมาย พร้อมแผนฮาร์ดแวร์
5. วางแผนการสาธิตการสอนและเตรียมตัวสู่ TQP Certified Trainer ตามกติกาของ TESA

## สิ่งที่ไม่อยู่ในชุดนี้

- **งานให้คะแนนในรายวิชา** เช่น โจทย์แล็บหลายชุดสำหรับสุ่ม และเกณฑ์ให้คะแนนละเอียด ไม่เผยแพร่สาธารณะ TESA จัดให้ผู้สอนเมื่อขอ ที่ contact@tesa.or.th
- **เนื้อหาของการสอบ TQP** ปิดสำหรับทุกคน รวมถึงผู้สอน ดู [tqp/certification.md](../../tqp/certification.md)
