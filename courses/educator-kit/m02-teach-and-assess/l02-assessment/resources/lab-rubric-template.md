# แม่แบบ rubric แบบจุดเดียว (single-point rubric) สำหรับแล็บ

ใช้คู่กับบทเรียน "ออกแบบการประเมิน" ของชุดสำหรับผู้สอน rubric แบบจุดเดียวเขียนเฉพาะเกณฑ์ "ผ่าน" ของแต่ละข้อ
แล้วให้ผู้ประเมินเขียนหลักฐานว่าต่ำกว่าหรือเกินเกณฑ์ตรงไหน เหมาะกับแล็บที่ผลงานแต่ละกลุ่มไม่เหมือนกัน

แม่แบบนี้เป็นโครงเปล่า ไม่มีโจทย์หรือเกณฑ์ของการสอบจริง

| เป้าหมายของบทเรียน (จาก `objectives`) | ต่ำกว่าเกณฑ์: สิ่งที่ยังขาด | เกณฑ์ผ่าน | เกินเกณฑ์: สิ่งที่ทำได้มากกว่า | หลักฐาน (ไฟล์ ภาพ log) |
|---|---|---|---|---|
| 1. | | | | |
| 2. | | | | |
| 3. | | | | |

## ตัวอย่างการเขียนเกณฑ์ผ่าน (จากบทเรียน explore.m01.l03)

| เป้าหมาย | เกณฑ์ผ่าน |
|---|---|
| สั่งหลอด LED กะพริบตามจำนวนรอบที่กำหนด | หลอดกะพริบครบตาม `TIMES` ตัวเลขบนจอตรงกับจำนวนครั้ง และโปรแกรมจบที่สถานะดับ |
| ทำนายผลก่อนรัน | มีคำทำนายที่เขียนก่อนรัน และอธิบายความต่างระหว่างคำทำนายกับผลจริงได้หนึ่งประโยค |

## ข้อควรจำ

- ทุกเป้าหมายต้องมีแถวของมัน ถ้าเป้าหมายไหนไม่มีหลักฐาน แปลว่ายังไม่ได้ประเมิน
- เกณฑ์ผ่านต้องสังเกตหรือตรวจได้ ไม่ใช้คำอย่าง "ดี" หรือ "เข้าใจ" โดยไม่บอกว่าดูจากอะไร
- ใช้ rubric เดียวกันทั้งผู้สอนและผู้เรียน ให้ผู้เรียนประเมินตัวเองก่อนส่ง
