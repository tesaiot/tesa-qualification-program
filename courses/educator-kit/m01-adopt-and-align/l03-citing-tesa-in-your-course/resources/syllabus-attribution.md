รูปแบบข้อความทั้งหมดมาจาก [ATTRIBUTION.md](../../../../../ATTRIBUTION.md) ที่รากของคลังความรู้ ถ้าสองที่ไม่ตรงกัน ให้ยึด ATTRIBUTION.md

## 1. เอกสารรายละเอียดรายวิชา (มคอ.3 หรือแบบฟอร์มที่สถาบันใช้แทน)

วางในหมวดทรัพยากรประกอบการเรียนการสอน หรือเอกสารและสื่ออ้างอิง หนึ่งรายการต่อหนึ่งหลักสูตรหรือบทเรียนที่ใช้

**กรณีใช้ตามต้นฉบับ**

```
รายวิชานี้ใช้สื่อการเรียนรู้แบบเปิดจาก TESA Open Knowledge ดังนี้
1. "<ชื่อหลักสูตรหรือบทเรียน>" จาก TESA Open Knowledge โดยสมาคมสมองกลฝังตัวไทย
   (Thai Embedded Systems Association: TESA) https://github.com/tesaiot/tesa-qualification-program
   สัญญาอนุญาต CC BY-NC 4.0
หมายเหตุ: รายวิชานี้ใช้สื่อเปิดของ TESA แต่ไม่ได้รับการรับรองจาก TESA หรือ Infineon
```

**กรณีดัดแปลง** (ตัด เพิ่ม แปล หรือเรียบเรียงใหม่)

```
รายวิชานี้ใช้และดัดแปลงสื่อการเรียนรู้แบบเปิดจาก TESA Open Knowledge ดังนี้
1. "<ชื่อหลักสูตรหรือบทเรียน>" จาก TESA Open Knowledge โดยสมาคมสมองกลฝังตัวไทย
   (Thai Embedded Systems Association: TESA) https://github.com/tesaiot/tesa-qualification-program
   สัญญาอนุญาต CC BY-NC 4.0 (ดัดแปลง: <สิ่งที่เปลี่ยน เช่น ปรับลำดับบทเรียนและเพิ่มแล็บของรายวิชา>)
หมายเหตุ: รายวิชานี้ใช้สื่อเปิดของ TESA แต่ไม่ได้รับการรับรองจาก TESA หรือ Infineon
```

ถ้าหลักสูตรที่ใช้มีเครดิตต้นทางอื่น (เช่น หลักสูตรที่ TESA ดัดแปลงจาก AIoT in Action ของ AIC) ให้คัดลอกเครดิตต้นทางจากท้ายหน้าหลักสูตรนั้นมาต่อท้ายรายการด้วย

**ฉบับภาษาอังกฤษ** (สำหรับหลักสูตรนานาชาติ)

```
This course uses open educational resources from TESA Open Knowledge:
1. "<title>" from TESA Open Knowledge by the Thai Embedded Systems Association (TESA),
   https://github.com/tesaiot/tesa-qualification-program, licensed under CC BY-NC 4.0 (adapted: <what changed>)
Note: this course uses TESA open material but is not certified by TESA or Infineon.
```

## 2. สไลด์ทุกหน้าที่นำมาใช้หรือดัดแปลง

ท้ายสไลด์ทุกหน้าที่มาจาก TESA Open Knowledge ใส่บรรทัดเครดิตสั้น

```
TESA Open Knowledge · © 2026 สมาคมสมองกลฝังตัวไทย (TESA) · CC BY-NC 4.0
```

สไลด์ Marp ในคลังมีบรรทัดนี้ใน `footer:` อยู่แล้ว ถ้าต้องการใส่ชื่อรายวิชาด้วย ให้ต่อกันในบรรทัดเดียว ห้ามลบของเดิม เช่น

```
footer: "<รหัสวิชา ชื่อวิชา> · TESA Open Knowledge · © 2026 สมาคมสมองกลฝังตัวไทย (TESA) · CC BY-NC 4.0"
```

และใส่ข้อความเต็ม (ข้อ 1) ไว้ในหน้าปกหรือหน้าสุดท้ายของชุดสไลด์ ถ้าดัดแปลง ให้เติม (ดัดแปลง: ...) ในข้อความเต็มนั้น

## 3. เอกสารแจกและใบงานแบบพิมพ์

```
ท้ายหน้า:  TESA Open Knowledge · © 2026 สมาคมสมองกลฝังตัวไทย (TESA) · CC BY-NC 4.0
หน้าแรก:   "<ชื่อบทเรียน>" จาก TESA Open Knowledge โดยสมาคมสมองกลฝังตัวไทย
           (Thai Embedded Systems Association: TESA) https://github.com/tesaiot/tesa-qualification-program
           สัญญาอนุญาต CC BY-NC 4.0 https://creativecommons.org/licenses/by-nc/4.0/
```

ผู้อ่านกระดาษกดลิงก์ไม่ได้ จึงพิมพ์ URL เต็มเสมอ

## 4. หน้าเว็บในระบบจัดการการเรียนรู้ (LMS) เช่น Moodle, Google Classroom

วางข้อความเต็มไว้ท้ายหน้าบทเรียนหรือหน้าแรกของรายวิชา และทำชื่อหลักสูตรกับชื่อสัญญาอนุญาตให้เป็นลิงก์

```
สื่อในหน้านี้มาจาก "<ชื่อบทเรียน>" จาก TESA Open Knowledge โดยสมาคมสมองกลฝังตัวไทย
(Thai Embedded Systems Association: TESA) https://github.com/tesaiot/tesa-qualification-program
สัญญาอนุญาต CC BY-NC 4.0 (ดัดแปลง: <ถ้ามี>)
```

## 5. สิ่งที่ห้ามเขียน

- "หลักสูตรที่ TESA รับรอง" "หลักสูตรเตรียมสอบ TQP" "Certified by TESA and Infineon" หรือข้อความใดที่ทำให้เข้าใจว่า TESA หรือ Infineon รับรองรายวิชา
  เว้นแต่รายวิชานั้นผ่านการเทียบกับ TQP ผ่าน TESA และได้รับอนุญาตเป็นลายลักษณ์อักษรแล้ว
- ใช้โลโก้ TESA หรือ TQP บนเอกสารรายวิชา ดู [TRADEMARKS.md](../../../../../TRADEMARKS.md)
