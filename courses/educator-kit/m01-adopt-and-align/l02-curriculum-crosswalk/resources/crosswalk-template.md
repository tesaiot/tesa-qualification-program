# ตารางเทียบรายบทเรียน (Curriculum Crosswalk)

ใช้คู่กับบทเรียน "ตารางเทียบผลลัพธ์การเรียนรู้" ของชุดสำหรับผู้สอน หนึ่งแถวต่อหนึ่งบทเรียนที่ใช้ในรายวิชา

## คำอธิบายคอลัมน์

| คอลัมน์ | เขียนอะไร |
|---|---|
| บทเรียน | id ถาวรของบทเรียน เช่น `explore.m01.l03` (ไม่ใช้เลขโฟลเดอร์ เพราะอาจถูกจัดลำดับใหม่) |
| CLO + กริยา Bloom | ผลลัพธ์การเรียนรู้ระดับรายวิชาที่บทเรียนนี้รับใช้ เขียนเป็น กริยาวัดผลได้ + เงื่อนไข + เกณฑ์ และวงเล็บระดับ Bloom |
| K / S / E / C | ด้านของผลลัพธ์การเรียนรู้ตามประกาศคณะกรรมการมาตรฐานการอุดมศึกษา พ.ศ. 2565: K ความรู้ · S ทักษะ · E จริยธรรม · C ลักษณะบุคคล |
| การประเมิน | ใช้อะไรเป็นหลักฐาน เช่น quiz ท้ายบท ไฟล์ฝึก แล็บ portfolio หรือ rubric |
| ชั่วโมง | บรรยาย / ปฏิบัติ / ศึกษาด้วยตนเอง (ดู `time_min` ของบทเรียนประกอบ) |
| หน่วยสมรรถนะ TPQI | ถ้าเกี่ยวข้อง เช่น ICT-CSOS-107B (พัฒนาฮาร์ดแวร์ระบบสมองกลฝังตัว) หรือ ICT-FYNH-108B (พัฒนาซอฟต์แวร์ระบบสมองกลฝังตัว) ของคุณวุฒิ นักพัฒนาระบบสมองกลฝังตัว ระดับ 4 |
| WA (TABEE) | คุณลักษณะบัณฑิตตาม Washington Accord (IEA GAPC 2021) ที่ได้รับการเสริม เช่น WA1 Engineering Knowledge, WA5 Tool Usage |
| skill id | ทักษะในแผนที่ทักษะ TESA ที่บทเรียนพัฒนา (จากช่อง `develops` ในหน้าบทเรียน) |

## คุณลักษณะบัณฑิต Washington Accord (IEA GAPC ฉบับ 2021) สำหรับอ้างอิง

WA1 Engineering Knowledge · WA2 Problem Analysis · WA3 Design/development of solutions · WA4 Investigation ·
WA5 Tool Usage · WA6 The Engineer and the World · WA7 Ethics · WA8 Individual and Collaborative Team work ·
WA9 Communication · WA10 Project Management and Finance · WA11 Lifelong learning
