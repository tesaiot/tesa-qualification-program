# Module 5 — Capstone: AIoT Mini-Product

> Capstone: AIoT Mini-Product · [Course page](../README.md)

Start from a real problem, design with a canvas and a schema, then assemble Sense → Decide → Show → Send into a mini-product that survives a network drop and can be presented in 10 minutes.

## Module objectives

Assemble everything learned into something usable, not just a demo: a clear problem, decisions made on the board, a screen that tells the truth about the network, events sent per your own designed schema, and a story you can tell someone else in ten minutes.

## Module checkpoint

You pass this module when you can do every item below (the details are in the **Lab** section of the hands-on lessons):

- [ ] All five boxes of the canvas are filled in, and you can tell the problem in 30 seconds
- [ ] The board reads → decides → shows on screen in a full loop, and runs continuously for at least 10 minutes
- [ ] The payload is JSON following the schema you designed, with a unit and a device id
- [ ] Cutting the network still leaves the screen working, showing an offline status, and it reconnects itself once the network returns
- [ ] A 10-minute presentation covering all four parts (problem → architecture → demo → limitations)
