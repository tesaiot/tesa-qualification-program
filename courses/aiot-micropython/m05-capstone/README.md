# โมดูล 5 — Capstone: AIoT Mini-Product

> Capstone: AIoT Mini-Product · [หน้าหลักสูตร](../README.md)

เริ่มจากโจทย์จริง ออกแบบด้วย canvas และ schema แล้วประกอบ Sense → Decide → Show → Send เป็น mini-product ที่อยู่รอดเมื่อเน็ตหลุด และนำเสนอ 10 นาที

## เป้าหมายของโมดูล

ประกอบทุกอย่างที่เรียนมาเป็นของที่ใช้งานได้ ไม่ใช่แค่ demo: โจทย์ชัด ตัดสินบนบอร์ด จอบอกความจริงเรื่องเน็ต ส่งเหตุการณ์ตาม schema ที่ออกแบบเอง และเล่าให้คนอื่นเข้าใจได้ในสิบนาที

## เช็กพอยต์ของโมดูล

ผ่านโมดูลนี้เมื่อทำได้ครบทุกข้อ (รายละเอียดอยู่ในหัวข้อ **แล็บ** ของบทเรียนลงมือทำ):

- [ ] canvas ห้าช่องกรอกครบ และเล่าโจทย์ได้ใน 30 วินาที
- [ ] บอร์ดอ่าน → ตัดสิน → แสดงบนจอ ครบวงจร และรันต่อเนื่องได้อย่างน้อย 10 นาที
- [ ] payload เป็น JSON ตาม schema ที่ออกแบบไว้ มีหน่วยและ device id
- [ ] ตัดเน็ตแล้วจอยังทำงาน ขึ้นสถานะ offline และต่อกลับเองเมื่อเน็ตกลับมา
- [ ] นำเสนอ 10 นาทีครบสี่ช่วง (ปัญหา → สถาปัตยกรรม → demo → ข้อจำกัด)
