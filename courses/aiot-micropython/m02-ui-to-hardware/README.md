# โมดูล 2 — จากจอสู่ฮาร์ดแวร์

> UI-to-Hardware Interfacing · [หน้าหลักสูตร](../README.md)

สั่ง LED และอ่านปุ่มด้วย gpio สร้างแผงควบคุมบนจอสัมผัสที่คุมไฟจริง แล้วอ่านลูกบิดและ CapSense พร้อมกรองสัญญาณ

## เป้าหมายของโมดูล

เขียน MicroPython ที่คุมฮาร์ดแวร์จริงและอธิบายได้ว่าเกิดอะไรขึ้นที่ขาไฟฟ้า: ไฟวิ่ง ปุ่มที่กันเด้ง แผงควบคุมสัมผัสที่สถานะบนจอตรงกับหลอดจริง และเกจลูกบิดกับแถบสัมผัสที่แสดงค่าดิบเทียบค่ากรองแล้ว

## เช็กพอยต์ของโมดูล

ผ่านโมดูลนี้เมื่อทำได้ครบทุกข้อ (รายละเอียดอยู่ในหัวข้อ **แล็บ** ของบทเรียนลงมือทำ):

- [ ] ไฟวิ่งครบทุกดวงที่ `gpio.num_leds()` บอก ปรับจังหวะได้ และกดปุ่มสิบครั้งตัวนับขึ้นสิบพอดี
- [ ] อธิบายได้ว่าถ้าเอาโค้ดกันเด้งออกจะเกิดอะไรขึ้นและเพราะอะไร
- [ ] แผงควบคุมสามสี: แตะเปิดปิดแล้วหลอดจริงตาม และสถานะบนจอตรงกับหลอดจริงในทุกกรณีที่ทดสอบ
- [ ] หมุนลูกบิดแล้วแถบเดินตลอดช่วง ไฟเกณฑ์ติดทีละดวง และค่ากรองนิ่งกว่าค่าดิบให้เห็นบนจอ
- [ ] ตอบได้ว่า `alpha` ของ EMA ค่าต่ำกับค่าสูงให้ผลต่างกันอย่างไร
