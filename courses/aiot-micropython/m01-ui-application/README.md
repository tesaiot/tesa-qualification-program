# โมดูล 1 — แอปพลิเคชันบนจอที่มีอยู่แล้ว

> Existing UI-based Application · [หน้าหลักสูตร](../README.md)

รู้จักบอร์ดจากแอปที่มากับเครื่อง ส่งข้อความแรกขึ้นจอด้วย lcd และ ui แล้วพาค่าจากบอร์ดออกไปบนเครือข่ายและรับคำสั่งกลับมา

## เป้าหมายของโมดูล

เห็นปลายทางของทั้งหลักสูตรจากเมนูที่มากับเครื่อง รู้ว่าบอร์ดมีสมองสองก้อนทำงานอะไร ส่งข้อความของตัวเองขึ้นจอได้ และพาบอร์ดออกเน็ตครั้งแรก: ต่อ WiFi ส่งค่าจริงขึ้น broker สาธารณะ แล้วรับคำสั่งกลับมาสั่งไฟบนบอร์ด

## เช็กพอยต์ของโมดูล

ผ่านโมดูลนี้เมื่อทำได้ครบทุกข้อ (รายละเอียดอยู่ในหัวข้อ **แล็บ** ของบทเรียนลงมือทำ):

- [ ] เล่นเมนูหลักครบห้าเมนู และบอกได้ว่าเมนูไหนใช้เซนเซอร์ตัวไหน
- [ ] จอบอร์ดขึ้นหัวเรื่อง ชื่อทีม ชื่อสมาชิก และบรรทัดสีเขียวปิดท้ายจากไฟล์ฝึก `s01_hello_lcd.py`
- [ ] ไฟล์ `09_your_level_rule.py` ผ่านครบหกแถว
- [ ] บอร์ดได้เลข IP ที่ไม่ใช่ `0.0.0.0` และอธิบายได้ว่าทำไมรหัสผิดถึงรอนานกว่ารหัสถูก
- [ ] ค่าจากบอร์ดขึ้นหน้าเว็บอ่านค่าของทีม หรืออ่านจากจอได้ว่าสายขาดที่ขั้นไหน และคำสั่งจากหน้าเว็บกลับมาสั่งไฟบนบอร์ดได้
