# usecase — ตัวอย่างประยุกต์

ตัวอย่างสั้น ๆ ที่หยิบรูปแบบจากงานจริงมาทำบนบอร์ด ใช้เป็นจุดตั้งต้นของโจทย์ต่อยอดและงาน capstone
สไลด์ของบทเรียน 5.3 รวมภาพหน้าจอของทั้งห้าไฟล์ไว้ในหัวข้อ "คลังตัวอย่างประยุกต์"

| ไฟล์ | เรื่อง |
|---|---|
| [01_andon_severity_lamp.py](01_andon_severity_lamp.py) | เสาไฟสถานะแบบโรงงาน (andon light) |
| [02_heartbeat_liveness.py](02_heartbeat_liveness.py) | ไฟหัวใจเต้น บอกว่าลูปยังไม่ตาย |
| [05_short_long_press.py](05_short_long_press.py) | ปุ่มเดียว สองความหมาย (กดสั้น กดยาว) |
| [07_hold_to_confirm.py](07_hold_to_confirm.py) | กดค้างเพื่อยืนยันคำสั่งที่ย้อนกลับไม่ได้ |
| [14_hard_iron_calibration.py](14_hard_iron_calibration.py) | การคาลิเบรตเข็มทิศ (hard-iron) เป็นสิ่งที่วัดได้ |

เลขหน้าชื่อไฟล์ไม่ต่อเนื่อง เพราะคัดมาเฉพาะไฟล์ที่สไลด์อ้างถึงจากชุดที่ใหญ่กว่า
