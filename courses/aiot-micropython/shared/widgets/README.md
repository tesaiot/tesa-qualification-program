# widgets — widget ทีละตัว

ไฟล์ในโฟลเดอร์นี้สาธิต **widget ตัวเดียวต่อหนึ่งไฟล์** ให้สั้นที่สุดเท่าที่ยังเห็นว่ามันทำอะไรได้
ไม่ผูกกับบทเรียนใด ไม่มีเรื่องราวประกอบ (`00_all_new_widgets.py` รวมหลายตัวไว้ในไฟล์เดียว)

มีไว้สองอย่าง

1. **ทดสอบบนบอร์ดจริง** ส่งไฟล์เดียวขึ้นบอร์ด แล้วดูว่า widget ตัวนั้นวาดออกไหม กดแล้วตอบไหม
2. **เป็นชุดตรวจสุขภาพ** หลังอัปเดตเฟิร์มแวร์ ถ้าไฟล์ไหนพัง แปลว่า widget ตัวนั้นเสีย
   โดยไม่ต้องเดาว่าพังเพราะอะไรในตัวอย่างที่ซับซ้อนกว่า

ไฟล์ใน `examples/` ของแต่ละบทเรียนสอนแนวคิดและใช้ widget เป็นเครื่องมือเล่าเรื่อง ส่วนไฟล์ที่นี่สอน widget ตัวนั้นเอง
หัวไฟล์ทุกไฟล์มีหัวข้อ **ดูที่จอ** และ **แบบไหนคือพัง** ให้เทียบกับสิ่งที่เห็น

## วิธีรัน

เปิดไฟล์ใน BENTO IDE แล้วกด Program to Device (เปิดหน้า BENTO Playground บนบอร์ดค้างไว้ก่อน)
หรือส่งขึ้นบอร์ดเป็น `/main.py` แล้วรีเซ็ต

## กติกาของชุดนี้

- หนึ่งไฟล์ต่อหนึ่ง widget ตั้งชื่อตาม widget
- รันจบเองได้ ไม่ค้างรอ input ไม่ต้องต่อเน็ต
- ข้อความเป็นภาษาไทย เพราะฟอนต์ไทยคือจุดที่ widget พังบ่อยที่สุด
- ตัวอักษรใช้ขนาด 28, 24 และ 20 เท่านั้น เป้าสัมผัสไม่ต่ำกว่า 88 px และวางบนกริด 8 px
