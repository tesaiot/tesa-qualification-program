# โมดูล 2 — การขึ้นรูป วัสดุ และการเรนเดอร์

*Modeling, Materials, and Render* · หลักสูตร [การออกแบบผลิตภัณฑ์เชิงอุตสาหกรรม (Blender และ Digital Twin)](../README.md)

## เป้าหมาย

พัฒนากล่องหยาบจากโมดูล 1 ให้มีรายละเอียดใช้งานจริงโดยไม่ทำลายขนาดที่ล็อกไว้ ใส่วัสดุ PBR จัดแสง และเรนเดอร์ภาพนำเสนอ

## บทเรียน

| # | บทเรียน | เนื้อหา |
|---|---|---|
| 1 | [รายละเอียดกล่อง วัสดุ PBR และภาพนำเสนอ](l01-modeling-materials-render/README.md) | Apply Scale, Solidify, Boolean, Bevel และการแยกฝา/ฐาน วัสดุ Principled BSDF แสงสามจุด กล้อง และการเรนเดอร์ |

## จุดตรวจ

ก่อนไปโมดูลถัดไป ตรวจว่าคุณทำสิ่งเหล่านี้ได้แล้ว:

- [ ] ช่องเปิด ≥ 2 จุด และฝา/ฐานแยกเป็นคนละ object
- [ ] PCB ยังใส่ได้ในมุมมอง Wireframe
- [ ] วัสดุ PBR ≥ 2 ชนิด และภาพเรนเดอร์ PNG ≥ 1 ภาพ
- [ ] กรอก material-lighting-sheet.md ครบ
