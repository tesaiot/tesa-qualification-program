
# Module 1 — Industrial Design Fundamentals

*Industrial Design Fundamentals* · [Product Industrial Design (Blender & Digital Twin)](../README.md) course

## Objectives

Lock the dimensions to the hardware before making it beautiful: think through the four lenses of industrial design, set Blender to millimetres, and build a block enclosure with correct clearance.

## Lessons

| # | Lesson | Content |
|---|---|---|
| 1 | [Industrial design principles and a to-scale enclosure](l01-industrial-design-fundamentals/README.md) | The four lenses of design work, the Concept → Block → Final sequence, the enclosure workflow, PCB clearance, and setting units and scale in Blender |
| 2 | [Lab: a block enclosure to hardware scale](l02-lab/README.md) | Setting up the scene and units, building a PCB placeholder, building an enclosure block with clearance, then naming and saving the file |

Approximate time per the original: about 2 hours (lessons) + a 90–120 minute lab.

Accompanying sheets and templates (in the `resources/` folder of lesson 1):

- [scale-and-block-checklist.md](l01-industrial-design-fundamentals/resources/scale-and-block-checklist.md)

## Checkpoint

Before moving to the next module, check that you can do the following:

- [ ] The Blender scene is Metric + Millimeters, per the team's convention
- [ ] A PCB placeholder at the measured size or the lab's stated size
- [ ] An enclosure block that fits over the PCB, with Apply Scale done and clear object names
- [ ] scale-and-block-checklist.md filled in completely
