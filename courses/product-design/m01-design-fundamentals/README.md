# โมดูล 1 — พื้นฐานการออกแบบเชิงอุตสาหกรรม

*Industrial Design Fundamentals* · หลักสูตร [การออกแบบผลิตภัณฑ์เชิงอุตสาหกรรม (Blender และ Digital Twin)](../README.md)

## เป้าหมาย

ล็อกขนาดให้ตรงฮาร์ดแวร์ก่อนทำให้สวย: คิดด้วยสี่เลนส์ของ industrial design ตั้ง Blender เป็นมิลลิเมตร และสร้างกล่องหุ้มแบบ block ที่มี clearance ถูกต้อง

## บทเรียน

| # | บทเรียน | เนื้อหา |
|---|---|---|
| 1 | [หลักออกแบบเชิงอุตสาหกรรมและกล่องหุ้มตามสเกลจริง](l01-industrial-design-fundamentals/README.md) | สี่เลนส์ของงานออกแบบ ลำดับ Concept → Block → Final ขั้นตอนกล่องหุ้ม PCB clearance และการตั้งหน่วยกับสเกลใน Blender |
| 2 | [แล็บ: กล่องหุ้มแบบ block ตามสเกลฮาร์ดแวร์](l02-lab/README.md) | ตั้งฉากและหน่วย สร้าง PCB placeholder สร้าง enclosure block ที่มี clearance แล้วตั้งชื่อและบันทึกไฟล์ |

เวลาโดยประมาณตามต้นฉบับ: ประมาณ 2 ชั่วโมง (บทเรียน) + แล็บ 90–120 นาที

ชีตและแม่แบบประกอบ (อยู่ในโฟลเดอร์ `resources/` ของบทเรียนที่ 1):
