# โมดูล 6 — การทำต้นแบบและโครงงานปิดหลักสูตร

*Prototyping and Final Project* · หลักสูตร [การออกแบบผลิตภัณฑ์เชิงอุตสาหกรรม (Blender และ Digital Twin)](../README.md)

## เป้าหมาย

ปิดวงจากแนวคิดถึงของจับต้องได้: เตรียม STL ตรวจ fitment กับบอร์ดจริง ทดสอบร่วมเฟิร์มแวร์หรือ Twin และส่งมอบ Design Report

## บทเรียน

| # | บทเรียน | เนื้อหา |
|---|---|---|
| 1 | [ไฟล์ผลิต ต้นแบบ fitment และ Design Report](l01-prototyping-final-project/README.md) | ตรวจ mesh และส่งออก STL ทางเลือกเมื่อยังพิมพ์ไม่ได้ ตรวจ fitment กับบอร์ดจริง ทดสอบร่วมเฟิร์มแวร์ และเขียน Design Report |
| 2 | [แล็บ Capstone: แพ็กเกจต้นแบบและ Design Report](l02-lab/README.md) | แก้ตามผลโมดูล 5 ตรวจ mesh ส่งออก STL พิมพ์หรือทำแผนพิมพ์ ตรวจ fitment ทดสอบร่วมเฟิร์มแวร์/Twin และส่ง Design Report |

เวลาโดยประมาณตามต้นฉบับ: ประมาณ 3 ชั่วโมง (บทเรียน) + แล็บ ~3 ชั่วโมง + เวลาพิมพ์/ประกอบต้นแบบแยกต่างหาก

ชีตและแม่แบบประกอบ (อยู่ในโฟลเดอร์ `resources/` ของบทเรียนที่ 1):

- [design-report-template.md](l01-prototyping-final-project/resources/design-report-template.md)

## จุดตรวจ

ก่อนไปโมดูลถัดไป ตรวจว่าคุณทำสิ่งเหล่านี้ได้แล้ว:

- [ ] `.blend` + `.glb` + STL อย่างน้อยหนึ่งไฟล์
- [ ] ตาราง fitment ที่กรอกจริง หรือแผนพิมพ์พร้อมหลักฐานการวัด
- [ ] บันทึกผลทดสอบร่วมเฟิร์มแวร์ / Twin / web-app
- [ ] Design Report ครบหัวข้อ และข้อเสนอแนะรอบถัดไป ≥ 3 ข้อ
