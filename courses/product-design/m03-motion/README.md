# โมดูล 3 — การเคลื่อนไหวและการโต้ตอบ

*Motion and Interaction* · หลักสูตร [การออกแบบผลิตภัณฑ์เชิงอุตสาหกรรม (Blender และ Digital Twin)](../README.md)

## เป้าหมาย

ใช้แอนิเมชันเป็นเครื่องมือตรวจกลไก: ตั้งบานพับ สร้างคลิปเปิด–ปิดที่ตั้งชื่อแล้ว และจับการชนของชิ้นส่วนก่อนพิมพ์จริง

## บทเรียน

| # | บทเรียน | เนื้อหา |
|---|---|---|
| 1 | [แอนิเมชันเปิด–ปิดและการตรวจการชน](l01-motion-and-interaction/README.md) | เตรียม pivot ของฝา keyframe เปิด–ปิด ตั้งชื่อ Action ตรวจการชนขณะเล่น และเตรียมคลิปสำหรับ Twin |
| 2 | [แล็บ: แอนิเมชันฝาและลำดับการเคลื่อนไหวสั้น](l02-lab/README.md) | ตั้งบานพับ keyframe คลิป `lid_open` สร้างคลิปปิด ตรวจการชน และบันทึกรายการคลิป |

เวลาโดยประมาณตามต้นฉบับ: ประมาณ 3 ชั่วโมง (บทเรียน) + แล็บ 2.5–3 ชั่วโมง

ชีตและแม่แบบประกอบ (อยู่ในโฟลเดอร์ `resources/` ของบทเรียนที่ 1):

- [animation-clip-list.md](l01-motion-and-interaction/resources/animation-clip-list.md)

## จุดตรวจ

ก่อนไปโมดูลถัดไป ตรวจว่าคุณทำสิ่งเหล่านี้ได้แล้ว:

- [ ] origin ของฝาอยู่ที่บานพับ
- [ ] คลิปเปิด/ปิดที่ตั้งชื่อเป็นภาษาอังกฤษสั้น เช่น `lid_open`
- [ ] ผลตรวจการชนบันทึกแล้ว
- [ ] กรอก animation-clip-list.md และมีหลักฐานภาพหรือคลิป
