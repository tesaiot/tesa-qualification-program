
# Module 4 — From Blender to Digital Twin

*Blender to Twin Integration* · [Product Industrial Design (Blender & Digital Twin)](../README.md) course

## Objectives

Export the model as a GLB with the correct size, correct axes, and clear clip names, then import it into a Twin host, define sensor and interaction points, and test it against clips or telemetry.

## Lessons

| # | Lesson | Content |
|---|---|---|
| 1 | [Exporting GLB and importing into a Twin host](l01-blender-to-twin/README.md) | What "Twin-ready" means, preparing the file before export, the glTF Binary workflow, post-import checks, sensor and interaction points, and a minimum test matrix |
| 2 | [Lab: export GLB and import into the Twin](l02-lab/README.md) | Preparing the file, exporting .glb, importing into a Twin host, marking sensor/interaction points, then testing with clips or data |

Approximate time per the original: about 3 hours (lessons) + a 2.5–3 hour lab.

Accompanying sheets and templates (in the `resources/` folder of lesson 1):

- [export-twin-checklist.md](l01-blender-to-twin/resources/export-twin-checklist.md)

## Checkpoint

Before moving to the next module, check that you can do the following:

- [ ] An enclosure_twin.glb file, plus the source .blend
- [ ] A screenshot of the model in Bitstream Studio at a usable size and orientation
- [ ] ≥ 1 named sensor/interaction point
- [ ] Clip or telemetry test results, and export-twin-checklist.md filled in completely
