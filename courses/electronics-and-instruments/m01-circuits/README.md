# โมดูล 1 · วงจรและอิเล็กทรอนิกส์พื้นฐาน

**เป้าหมายของโมดูล** คำนวณและออกแบบวงจรพื้นฐานที่พบบนบอร์ดพัฒนา

สถานะ **pre-alpha** (อยู่ระหว่างเขียน) · เวลาโดยประมาณ 195 นาที

| บทเรียน | เรื่อง | เวลา |
|---|---|---|
| [elec.m01.l01](l01-voltage-current-resistance/README.md) | แรงดัน กระแส และความต้านทาน | 65 นาที |
| [elec.m01.l02](l02-dividers-and-sensors/README.md) | วงจรแบ่งแรงดันและเซนเซอร์แบบอนาล็อก | 65 นาที |
| [elec.m01.l03](l03-components/README.md) | ชิ้นส่วนพื้นฐาน: ตัวต้านทาน ตัวเก็บประจุ ไดโอด และทรานซิสเตอร์ | 65 นาที |

## Checkpoint ท้ายโมดูล

- [ ] คำนวณตัวต้านทานจำกัดกระแสของหลอด LED หนึ่งดวงได้
- [ ] อธิบายว่าลูกบิดบนบอร์ดคือวงจรแบ่งแรงดัน และค่าที่ ADC อ่านได้สัมพันธ์กับแรงดันอย่างไร
