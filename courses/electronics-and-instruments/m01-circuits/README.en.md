# Module 1 · Circuits and basic electronics

**Module goal:** calculate and design the basic circuits found on a development board.

Status **alpha** (in trial use) · about 195 minutes

**You need:** a calculator, a breadboard, a basic resistor set, an LED, a 100 µF capacitor, a multimeter, and a board (the part reading a knob through the ADC uses the TESAIoT Dev Kit)

| Lesson | Topic | Time |
|---|---|---|
| [elec.m01.l01](l01-voltage-current-resistance/README.md) | Voltage, current and resistance | 65 minutes |
| [elec.m01.l02](l02-dividers-and-sensors/README.md) | Voltage dividers and analogue sensors | 65 minutes |
| [elec.m01.l03](l03-components/README.md) | Basic components: resistors, capacitors, diodes and transistors | 65 minutes |

## Module checkpoint

- [ ] can calculate the current-limiting resistor for one LED
- [ ] can explain that a knob on the board is a voltage divider, and how the value the ADC reads relates to the voltage
- [ ] can explain why every chip has its own decoupling capacitor, and when a MOSFET is needed to drive a load
