# โมดูล 4 · Logic analyzer และ protocol analyzer

**เป้าหมายของโมดูล** จับสัญญาณดิจิทัลและถอดรหัสโปรโตคอลเพื่อพิสูจน์ว่าบนสายเกิดอะไรขึ้นจริง

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 130 นาที

**ต้องใช้** logic analyzer ที่ใช้กับ PulseView ได้ และ TESAIoT Dev Kit ที่ flash ตัวอย่าง QWA309 Header I/O Test ไว้

| บทเรียน | เรื่อง | เวลา |
|---|---|---|
| [elec.m04.l01](l01-capture-a-signal/README.md) | จับสัญญาณดิจิทัลครั้งแรก | 65 นาที |
| [elec.m04.l02](l02-decode-i2c-and-uart/README.md) | ถอดรหัส I2C และ UART | 65 นาที |

## Checkpoint ท้ายโมดูล

- [ ] จับสัญญาณกะพริบบนขา header แล้ววัดความกว้างพัลส์และความถี่
- [ ] ถอดรหัส I2C ของการสแกนบัสได้ครบ address และ ACK และเทียบกับผลบนจอ
- [ ] ถอดรหัส UART ที่ 115200 baud และอธิบายอาการเมื่อตั้ง baud ผิด
