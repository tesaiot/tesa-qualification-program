# โมดูล 3 · มัลติมิเตอร์

**เป้าหมายของโมดูล** วัดแรงดัน ความต่อเนื่อง และกระแสอย่างปลอดภัยและถูกวิธี

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 130 นาที

**ต้องใช้** มัลติมิเตอร์พร้อมคู่มือ เบรดบอร์ด LED ตัวต้านทาน และบอร์ด

| บทเรียน | เรื่อง | เวลา |
|---|---|---|
| [elec.m03.l01](l01-voltage-and-continuity/README.md) | วัดแรงดันและความต่อเนื่อง | 65 นาที |
| [elec.m03.l02](l02-current-safely/README.md) | วัดกระแสอย่างปลอดภัย | 65 นาที |

## Checkpoint ท้ายโมดูล

- [ ] วัดแรงดัน 3.3 V และแรงดันจากลูกบิดบนบอร์ดได้ และเทียบกับค่าที่ ADC อ่าน
- [ ] วัดกระแสของหลอด LED หนึ่งดวงด้วยการต่ออนุกรม แล้วย้ายสายแดงกลับช่อง VΩ ทุกครั้ง
- [ ] หาจุดลัดวงจรบนวงจรที่ปิดไฟแล้วด้วยโหมดความต่อเนื่อง
