# โมดูล 6 · ต่อวงจร บัดกรี อ่านแผนผัง และพื้นฐาน PCB กับ EMC

**เป้าหมายของโมดูล** ประกอบวงจรต้นแบบได้เอง อ่านแผนผังวงจรของบอร์ด และเข้าใจหลักการออกแบบแผ่นวงจรเบื้องต้น

สถานะ **alpha** (ทดลองใช้) · เวลาโดยประมาณ 260 นาที

**ต้องใช้** เบรดบอร์ด หัวแร้งและอุปกรณ์ความปลอดภัย แผ่นฝึกบัดกรี แผนผังของบอร์ด มัลติมิเตอร์ และออสซิลโลสโคป

## Checkpoint ท้ายโมดูล

- [ ] ต่อวงจร LED กับปุ่มบนเบรดบอร์ดตามแผนผังได้ในครั้งเดียว และตรวจก่อนจ่ายไฟ
- [ ] บัดกรีหัวต่อหนึ่งแถวให้ผ่านการตรวจด้วยตาและมัลติมิเตอร์
- [ ] ชี้ส่วน decoupling กราวด์ และสัญญาณความเร็วสูงบนแผนผังของบอร์ดได้
