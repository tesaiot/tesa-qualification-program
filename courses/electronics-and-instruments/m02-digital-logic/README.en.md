# Module 2 · Digital circuits

**Module goal:** understand logic levels and wire a digital input so it reads reliably.

Status **alpha** (in trial use) · about 130 minutes

**You need:** a TESAIoT Dev Kit flashed with the QWA309 Header I/O Test example, a breadboard, a push button, a resistor, a multimeter, and a logic analyzer

| Lesson | Topic | Time |

## Module checkpoint

- [ ] can decide from datasheet values whether a 1.8 V device and a 3.3 V device can be wired directly together
- [ ] can wire a button as active-low with a pull-up, and explain why it reads 0 when pressed
- [ ] can measure a button's bounce with a logic analyzer and choose a debounce time from the data
