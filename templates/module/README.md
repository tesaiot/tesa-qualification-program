## เป้าหมายของโมดูล

เมื่อจบโมดูลนี้ คุณจะ«ความสามารถหนึ่งอย่างที่โมดูลนี้สร้าง เขียนด้วยกริยาที่วัดผลได้ เช่น สร้างแผงควบคุมบนจอสัมผัสที่สั่งไฟบนบอร์ดได้จริง»

ใช้เวลาประมาณ «N» ชั่วโมง · ระดับ «L2»

## Checkpoint

งานปิดท้ายโมดูลที่ผู้เรียนต้องทำได้ด้วยตัวเองก่อนไปโมดูลถัดไป

- **โจทย์:** «งานเล็ก ๆ ที่รวมทุกบทเรียนในโมดูล ทำบนบอร์ดหรือ BENTO Emulator»
- **ผ่านเมื่อ:** «เกณฑ์ที่ตรวจได้ เช่น โปรแกรมทำงานครบทุกข้อในรายการ และอธิบายได้ว่าทำไมใช้วิธีนี้»
- **หลักฐาน:** «สิ่งที่เก็บไว้ใน portfolio เช่น ไฟล์โค้ด ภาพหน้าจอ หรือวิดีโอสั้น»

## ไปต่อ
