# Literal values that tools/validate.py (check `secrets`) accepts in published code under courses/.
# Same format and rule as the AIoT course's tools/credentials_allow.txt: one value per line,
# `VALUE | reason`. A value with no reason is ignored — writing the reason IS the review.
#
# The bar: the value must be something a learner is meant to READ and then replace, or a value
# that is public by design. A password to any real network, broker or account never qualifies.
# A placeholder in angle brackets (<รหัสผ่านของคุณ>) or an empty string never needs a line here.
#
# Deliberately NOT carried over from the AIoT course's list (TESA Open Knowledge has no classroom):
#   aiot12345 (the classroom capstone AP password) and bento (the classroom practice broker's
#   password). BUILD_SPEC §1.4 forbids publishing WiFi passwords and broker credentials, so code
#   that still carries them fails validation until it uses a <placeholder>.

changeme | the placeholder word itself; the lesson tells the learner to change it before running
12345678 | the password the BOARD sets on its own SoftAP (WPA2 minimum length), printed in the lesson; not a network secret
